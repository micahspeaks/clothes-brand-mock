# NULL THEORY — Clothing Website

An original static streetwear website built with HTML, CSS, and JavaScript.

## Upload to GitHub Pages

1. Extract this ZIP file.
2. Create a new GitHub repository.
3. Upload everything **inside** the `null-theory-clothing` folder to the repository root.
4. Keep the `assets` folder and its three PNG images intact.
5. Open **Settings → Pages**.
6. Choose **Deploy from a branch**.
7. Select `main` and `/ (root)`, then save.

No installation or build command is required.
